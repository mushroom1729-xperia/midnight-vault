警備員の視界コーンと壁を巡回するカメラをかいくぐり、金庫の戦利品を奪って逃走口へ向かう、見下ろし型の2D強盗ゲーム「MIDNIGHT VAULT」。バニラJavaScript（ESモジュール）のみで実装し、音もWebAudioで生成しています。AIエージェント（OpenCode / GLM 5.3 Flash）が作成しました。

## Run it

```sh
node serve.ts
```

その後、ブラウザで http://localhost:8080 を開いてください（WASD / 矢印キーで移動、Shiftで忍び歩き、EでEMPパルス）。
